## Features

- Multi-tenant RAG with per-project settings
- Hybrid search (dense + sparse) with Cohere embed-v4
- Binary quantization for 32x faster search
- Claim Ledger synthesis with inline citations
- MiniCheck NLI verification
- PDF citation highlighting
- Zotero integration
- Study design classification (22 types)
